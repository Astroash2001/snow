1. Mute (D-10, VOIC-03): the `mute` command matched by plan 01-18 -> `source.close()` (the Windows microphone indicator turns off because the stream is closed, not ignored), publish `mute.changed(muted=True, by="voice")`, `presence.state(state="muted")`, `conversation.ended(end_reason="mute")`, and `turn.cancelled(cancel_reason="mute")` if a turn or reply is in flight. While muted the engine is in `MUTED` and nothing is processed. Unmute exists only through `cmd.mute.set` (HUD button, orb, tray, mini menu): on `muted=False` reopen the source and publish `mute.changed(False, by=command.by)` and presence sleeping. Also publish `running` rows for `wake_word` (after the model loads) and `speech_to_text` (label "Speech to text"; status `down` with detail "No Groq key. Run snow setup." when the key is missing; plan 01-22 adds the local fallback).

3. `tests/voice/test_mute.py`: fake source recording open/close calls, in-process hub for command routing and persisted state, per the behavior block.
