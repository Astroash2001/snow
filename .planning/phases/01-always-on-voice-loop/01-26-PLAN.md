2. `tts/base.py`: `EngineName = Literal["pocket_tts","cartesia","chatterbox","kokoro"]`; `TtsEngine` protocol with `name`, `sample_rate`, `voice_name`, `load() -> None` (raises `EngineLoadError`), `async stream(text: str, emotion: str) -> AsyncIterator[numpy.ndarray]` (mono float32 chunks), `cancel() -> None`; `EngineError(kind: Literal["load_failed","unreachable","out_of_credits","no_key","budget_reached"])`.

3. `tts/text.py`: `sanitize(text) -> str` removes markdown emphasis and headings, code fences and inline code, replaces URLs with nothing speakable (drop them), strips emoji and bracket residue; `SentenceChunker` with `feed(delta) -> list[str]` and `flush() -> list[str]`: the first chunk is released at the first clause boundary (comma, semicolon, colon or dash) once it has at least 3 words, otherwise at the first sentence end; later chunks at sentence ends (`.`, `!`, `?`), not splitting decimals like 3.5 or common abbreviations (Mr., Dr., e.g., i.e.).

4. `tts/pocket.py`: `PocketEngine(cfg)` loads the Pocket TTS model on CPU (`torch.set_num_threads(cfg.torch_threads)`, default 4; CPU device only, the GPU stays free, D-39) and the voice state from `cfg.voice` (a licensed English male preset voice from Kyutai's catalog until the user's audition in plan 01-32, D-05; record the preset's licence in the SUMMARY). `stream()` runs the library's streaming generation in a worker thread and hands chunks to the event loop through an `asyncio.Queue`; `cancel()` stops generation at the next chunk. Read the installed API for the exact names (model loading, voice state from preset or wav, streaming generator, sample rate). Set `HF_HUB_DISABLE_IMPLICIT_TOKEN=1` in the voice worker before the first model download (a stale cached Hugging Face token makes public repositories fail, research Pitfall 14); if the weights turn out to be gated, stop and report it as an auth gate for the user.

5. `playout.py`: `Playout(sample_rate, cfg)` around `sounddevice.OutputStream` (mono float32, blocksize 20 ms, `WasapiSettings(auto_convert=True)`), a thread-safe ring buffer, `start_utterance()`, `push(chunk)`, `end_utterance()`, `abort()` (clear the buffer and `stream.abort()` then restart, so the tail is at most one block), callbacks `on_first_audio(ts_ns)`, `on_level(level)` (RMS per block, -60..0 dBFS mapped to 0..1, at most every 31 ms) and `on_drained()`. Start playback of local-engine audio only after `prebuffer_ms` (config, default 300; lower it in config if measured RTF allows, research F2).

6. `config/tts.toml` + `tts/config.py` (`TtsConfig`): `[router] order = ["cartesia", "chatterbox", "pocket_tts", "kokoro"]` (D-33 order, consumed by plan 01-28's router); `[playout] prebuffer_ms = 300`; `[engines.pocket_tts] enabled = true`, `voice = "<preset>"`, `torch_threads = 4`; `[engines.kokoro]`, `[engines.cartesia]` and `[engines.chatterbox]` with `enabled = false` (plans 01-28, 01-31 and 01-33 enable them).

7. Pipeline: on `reply.delta` for the active turn feed `SentenceChunker`, speak each chunk in order with Pocket TTS (plan 01-28 inserts the router), publish `presence.state(speaking)` at the first output sample, `audio.level(channel="tts")` while speaking, `presence.state(listening)` and `engine.reply_finished()` on drain (moving the silence-timer resume from `reply.final` to end of playback), and `tts.spoken(engine, chars, first_audio_ms)` per reply. A `reply.final` with empty text and no deltas (the silent fallback, D-41) plays nothing, publishes no speaking state and calls `engine.reply_finished()` at once. Publish `voice.status(engine="pocket_tts", voice_name, voice_role="everyday", credits_remaining=None, cartesia_available=False, cartesia_reason=None)` at startup and `health.subsystem(name="speech_output", label="Speech output", owner="voice")` running after load.
