## Phase Goal

**As a** developer, **I want to** wake Snow by voice and talk with it naturally, **so that** I can speak to my PC instead of typing.

This plan is a supply-chain gate, not a feature slice. The voice stack changed after research (CONTEXT.md D-32 to D-41), so four packages the later plans need were never part of the RESEARCH.md Package Legitimacy Audit. Under the package legitimacy gate they are treated as `[ASSUMED]` and need a human check before installation.

<objective>
Have the user verify, on the official registries and upstream repositories, the four packages that are not covered by the research audit, before any plan installs them.

Purpose: Snow will run always-on with access to the microphone and stored API keys; a typosquatted or compromised voice package would sit inside that trust boundary (CLAUDE.md supply-chain posture; the 2026 LLM-proxy package incident).
Output: a recorded approve/reject verdict per package in `01-02-SUMMARY.md`.
</objective>
