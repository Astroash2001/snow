1. `config/snow.toml`: `[hub] allowed_origins = ["http://localhost:5173"]`, `retention_days = 30` (D-19, used by plan 01-14), and `[workers.brain] command = ["{python}", "-m", "snow.brain"]`, `[workers.voice] command = ["{python}", "-m", "snow.voice"]`, `[workers.hud] command = ["hud/node_modules/electron/dist/electron.exe", "hud"]`, each `enabled = true`; `{python}` expands to `sys.executable`, relative paths resolve from `repo_root()`. Workers for modules not built yet simply exit or fail to launch and are logged; plans 01-09 and 01-13 make them real without editing this file.

2. `src/snow/hub/__main__.py`: `main()` calls `snow.logging.configure("hub")`, opens `EventLog(data_dir()/"data"/"snow.db")`, starts `Hub(event_log, allowed_origins=..., run_dir=run_dir())` on port 0, then launches each enabled `[workers.*]` entry with `subprocess.Popen` (flag `CREATE_NO_WINDOW`), passing `SNOW_HUB_URL` and `SNOW_TOKEN` and an environment copy from which every variable whose name contains KEY, TOKEN, SECRET or PASSWORD (case-insensitive, except `SNOW_TOKEN`) is removed. A launch error (missing executable) or a worker exit is logged with the error or exit code and never stops the hub. Ctrl+C stops the hub and terminates the children. The hub is a per-user process, never a Windows Service (D-40; plan 01-14 replaces this launcher with the supervisor and Job Object).

3. `src/snow/cli.py`: `COMMANDS` table mapping command names to lazily imported `"module:function"` strings for every Phase 1 command: `run` -> `snow.hub.__main__:main`, `setup` -> `snow.config.setup:main`, `install-autostart` -> `snow.hub.autostart:install`, `uninstall-autostart` -> `snow.hub.autostart:uninstall`, `dev say` -> `snow.devtools:say`, `dev kill` -> `snow.devtools:kill`, `dev inject-wav` -> `snow.voice.devinput:main`, `dev probe-models` -> `snow.brain.probe:main`, `dev audition-voices` -> `snow.voice.audition:main`, `dev record-negatives` -> `snow.voice.record_negatives:main`. `main(argv=None)` dispatches; `--help` lists all commands; a target module that is not importable yet prints `snow: '<name>' is not available in this build` and exits 2.

4. `src/snow/devtools.py`: `say(argv)` (`snow dev say <text> [--timeout S]`, default 30) connects as role `dev` with `HubClient` details from `hub.json`, sends `cmd.dev.say`, prints each `reply.delta` and exits 0 on the matching `reply.final` (timeout -> exit 1 with "no reply"); `kill(argv)` sends `cmd.dev.kill` (handled by plan 01-14). This is the developer-only test input of D-07, not a user-facing feature.

5. `tests/test_cli.py`: `main(["--help"])` lists `run`, `setup` and `dev say`; with `COMMANDS` monkeypatched to include an entry pointing at a missing module, dispatch prints the "not available in this build" line and exits 2.
