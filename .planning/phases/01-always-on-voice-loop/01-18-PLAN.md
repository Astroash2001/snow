3. Pipeline commands: after STT, `match_command` runs before publishing. `end` -> `conversation.ended(end_reason="phrase")`, presence sleeping/awake. `sleep` -> `conversation.ended(end_reason="sleep")`, presence sleeping with mode `soft_sleep` (D-10 soft sleep: mic on, wake phrase only); a later wake sets mode `awake`. `mute` is handled by plan 01-20 (until then it is matched and ignored, so it never reaches the brain). Matched commands publish no `transcript.final`. Presence transitions: wake -> listening; turn end -> thinking; `reply.final` from the hub (or a 20 s timeout when no reply arrives) -> listening; conversation end -> sleeping. Mic level: RMS of each 512-sample chunk mapped from -60..0 dBFS to 0..1, published as `audio.level(channel="mic")` at most every 31 ms, only while presence is listening.
