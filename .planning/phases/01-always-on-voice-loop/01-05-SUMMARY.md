# Phase 1 Plan 05: Synthetic Audio Fixtures Summary

**A single command regenerates 13 deterministic kokoro-onnx speech fixtures (bm_george), and `--check` proves every wake fixture fires the openWakeWord hey_jarvis stand-in while the TV negative never does**

## Performance

- **Duration:** about 25 min (kokoro synthesis is about 90 s per full run)
- **Tasks:** 1 (tracer)
- **Files:** 14 created

## Accomplishments
- `uv run python scripts/make_audio_fixtures.py` synthesizes and writes all 13 WAVs, then runs the check; `--check` alone verifies the committed files without rewriting.
- Reruns are byte-stable: all 13 SHA-256 hashes were identical across two full regenerations.
- Total fixture size is 2,858,842 bytes (about 2.7 MiB), of which `tv_negative.wav` is 960 KB.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing critical] Tone fixtures also checked as wake negatives**
- **Found during:** Task 1
- **Issue:** Plan only required the wake negative check on `tv_negative`; tone fixtures carry no wake phrase and a false wake there would silently corrupt tone tests.
- **Fix:** `--check` also requires `tone_calm` and `tone_stressed` to stay below 0.5.
- **Files modified:** scripts/make_audio_fixtures.py

**2. [Rule 2 - Missing critical] SHA-256 pinning of kokoro model downloads**
- **Found during:** Task 1
- **Issue:** Plan 01-28 will pin kokoro files for runtime; the fixture script also downloads and runs them (T-01-SC).
- **Fix:** Script verifies the two release assets against pinned digests and deletes a mismatching download.

**3. [Resampler] scipy resample_poly (24 kHz to 16 kHz)**
- `scipy` is not a direct dependency (it arrives transitively with the Pipecat/kokoro lock); no pyproject or uv.lock change was made. If scipy ever drops out of the lock, swap to `soxr`, which is also transitive.

**Total deviations:** 2 auto-added hardening items plus 1 implementation note. **Impact:** none on scope.
