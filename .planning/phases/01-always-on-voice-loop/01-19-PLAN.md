1. `sphere.ts`: deterministic geometry from a seed: N nodes on a Fibonacci sphere (about 220 nodes at 192 px, 36 at 40 px), edges to each node's 3 nearest neighbours, edge glyph positions sampled along each edge; glyph assignment from a set mixing ASCII symbols, digits and short code fragments (`for`, `{}`, `=>`, `0x`, `json`, `1`, `0`). Typed arrays for positions; rotation about Y applied per frame.

2. `atlas.ts`: pre-render every glyph once per (hue, brightness level 0-3, size class) into an `OffscreenCanvas` atlas with the glow baked in (shadowBlur on brightest levels only); colors blend from the state hue toward violet `#A78BFA` by depth. The frame loop does no text layout at all; it only blits atlas cells. Rebuild the atlas only on state change (cached per state).

3. `renderer.ts`: `OrbRenderer(canvas, { size, seed, fpsCap })` with `setState(state)`, `setAlert(on)`, `frame(now, level)`, `start()`, `stop()`. Motion per UI-SPEC: sleeping = slate `--snow-state-sleeping` at 45% opacity, 6 s breathing, ignores audio, 15 fps; listening = cyan, core scales with mic level and a thin outer ring expands with level; thinking = violet 2.4 s pulse and rotating gradient, ignores audio; speaking = pink, core scales with TTS level, solid soft glow, no ring; muted = red desaturated core, completely static, microphone-slash glyph drawn over the orb; offline = `--snow-state-offline` dashed outline only, no fill. Alert marker: when `alert` is on, an 8 px `--snow-alert` dot on the orb's top edge (the UI-SPEC alert dot), drawn in every state; this is how the orb shows its alert state when every language model is down and Snow stays silent (D-41). Depth sets glyph alpha and size (brighter nodes, dimmer lines); slow rotation; glyphs flicker to new characters at a low rate. A state change paints the new hue on the very next frame, then cross-fades for 120 ms. `smoother.ts`: attack 40 ms, release 200 ms exponential smoother with `reset()`; scale = `1 + 0.18 * level`; speaking -> listening resets it (no ring-out). `prefers-reduced-motion: reduce` turns off breathing, pulse, rotation and flicker and caps the scale at +6%. FPS caps: 60 (dashboard), 15 while sleeping; `document.visibilityState === "hidden"` cancels the `requestAnimationFrame` loop entirely. No glow or lighting outside the orb.

4. `levels.ts`: a mutable `{ mic: number, tts: number, updatedAt }` ref. In `ws.ts` route `audio.level` messages into it (channel mic or tts) before the reducer and never into React state. `Presence.tsx`: props `{ state, size, alert }`, owns one `<canvas>` inside a `<button aria-label="Snow, {state word}">`; listening reads `levels.mic`, speaking reads `levels.tts`; offline while the connection is not online or before the first snapshot; plan 01-25 reuses it at 40 px with `fpsCap` 30. `App.tsx` puts the 192 px Presence in the Presence card above the state word and computes `alert` from the store: any subsystem with status down or restarting, or any role with status failing.

5. Deterministic test hook: `hud/src/main/index.ts` appends `?snowtest=1` to the dashboard URL only when `SNOW_HUD_TEST=1` is set in the main-process environment; the renderer then exposes `window.__snowTest.freezeOrb(seed)` (fixed seed, animation frozen) for the visual regression of plan 01-23. Without the flag nothing is exposed.

6. Perf instrumentation: `ws.ts` calls `performance.mark("evt:" + seq)` on receipt of `presence.state`; the renderer calls `performance.mark("paint:" + seq)` in the first rAF callback that draws that state. `hud/e2e/perf.spec.ts`: using `startMockHub`'s `send()`, push 200 `presence.state` events alternating states at 100 ms intervals; read the marks from the page and assert p95 of paint minus evt is at most 50 ms and the maximum is at most 100 ms; also assert the average draw time per frame at 192 px is under 4 ms (measured around `frame()`), and that a `health.role` with status failing shows the alert marker (read through the test hook). `orb.test.ts` (Vitest): the smoother's attack and release curves, geometry determinism for a seed, reduced-motion scale cap.
