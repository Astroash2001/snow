3. Event log. `src/snow/hub/migrations/001_init.sql` creates `events(seq INTEGER PRIMARY KEY AUTOINCREMENT, ts_ns INTEGER NOT NULL, type TEXT NOT NULL, source TEXT NOT NULL, correlation_id TEXT, turn_id TEXT, causation_id INTEGER, user_id TEXT NOT NULL DEFAULT 'owner', risk_tier TEXT NOT NULL DEFAULT 'free', reason TEXT, result TEXT, payload TEXT NOT NULL, content TEXT)`, indexes on `ts_ns` and `(type, seq)`, and `state(key TEXT PRIMARY KEY, value TEXT NOT NULL)`. `src/snow/hub/eventlog.py`: `EventLog(path)` opens stdlib `sqlite3`, sets `PRAGMA journal_mode=WAL; PRAGMA synchronous=NORMAL; PRAGMA foreign_keys=ON`, applies `migrations/NNN_*.sql` files whose number exceeds `PRAGMA user_version` and bumps it; `append(event) -> int` writes envelope columns, puts the field named by `content_field` into `content` and every other non-envelope field as JSON into `payload`; `rows(types: list[str] | None = None) -> list[sqlite3.Row]`; `get_state(key)`/`set_state(key, value)`; `close()`. Speech text lives only in `content` (D-18: text transcripts, never audio). Writes happen synchronously on the hub loop (shortcut: durable events are a few per second; move to a writer thread if a profile ever shows loop stalls).

4. Hub. `src/snow/hub/server.py`: `Hub(event_log, *, allowed_origins: list[str], run_dir: Path)` with `async start(port: int = 0)` and `async stop()`; plans 01-03 and 01-06 build on this exact constructor. `start` uses `websockets.asyncio.server.serve` bound to `127.0.0.1`, `max_size=1_048_576`, and a `process_request` hook that rejects (HTTP 403) a request whose `Host` is not `127.0.0.1:<port>` or whose `Origin` header is present and not one of `null`, `file://`, or an entry of `allowed_origins`. Token: `secrets.token_hex(32)` per hub launch. Write `run_dir/hub.json` with `{"port", "token", "pid"}`. First message must be a valid `Hello` with matching token within 2 seconds, else close with code 4401. Every inbound message is validated with `WireMessage` (extra fields forbidden); invalid input closes the socket with 4400. After a valid hello the hub sends `SnapshotMsg(snapshot=Snapshot(last_seq=<last durable seq>))` first. An event's `source` must equal the sender's role (hub-originated events use `hub`). For durable events the hub assigns `seq` from `EventLog.append` and then broadcasts to every connected client; ephemeral events are broadcast only. `cmd.dev.say` from role `dev` makes the hub emit `TranscriptFinal(source="dev", text=..., correlation_id="dev-<uuid4 hex>", turn_id="<uuid4 hex>")` (D-07: the developer-only test input, not a user-facing feature).
