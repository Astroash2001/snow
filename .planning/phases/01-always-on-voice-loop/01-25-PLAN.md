1. Second renderer entry: `hud/src/renderer/mini.html` + `src/mini.tsx`, added to the electron-vite renderer `rollupOptions.input` next to `index.html`. The mini renderer opens its own hub connection with the same `connectHub` (role hud) and the same reducer.

2. `windows.ts` `WindowManager`: dashboard `close` and `minimize` events call `preventDefault` (for close), hide the dashboard and show the mini; `openDashboard()` shows and focuses the dashboard and hides the mini; never both visible (D-11). On hide, send `chrome:visibility` false to the dashboard renderer, which cancels the orb rAF loop and unmounts the transcript and health trees (`App.tsx`); on show, send true and the renderer sends `cmd.snapshot` and remounts. Mini `BrowserWindow`: `frame: false`, `transparent: true`, `alwaysOnTop: true` then `setAlwaysOnTop(true, 'floating')` (not screen-saver, so it does not cover fullscreen games), `skipTaskbar: true`, `focusable: false`, `resizable: false`, 320x56, default position top-right of `screen.getPrimaryDisplay().workArea` with 16 px margins, same secure webPreferences as the dashboard. Call `mini.setIgnoreMouseEvents(true, { forward: true })` at creation; IPC `mini:hover` (true on orb `pointerenter`, false on `pointerleave`) toggles it; the caption pill and empty area stay click-through always. IPC `mini:click` opens the dashboard (plan 01-27 adds drag versus click). `hud/src/main/index.ts` creates the WindowManager instead of the single window.

3. `MiniIndicator.tsx`: row `[caption pill][orb 40px]` with the orb at the screen-side edge (plan 01-27 mirrors it); `Presence` at size 40 with `fpsCap` 30 (fewer, larger, brighter glyphs) and the same `alert` value the dashboard computes (any subsystem down or restarting, or a role failing), which draws the 8 px alert dot on the orb's top edge (D-41). Caption shows the user's words only (partial then final): 120 ms fade-in on the first partial of a turn, updates in place, holds 2.5 s after the final, 400 ms fade-out, never shown while sleeping; single line, max width 256 px, height 32 px, padding 8 px 16 px, Body text, overflow shows the newest words with a 24 px left mask fade; the window never resizes. Hard mute shows a persistent "Muted" pill (from copy.ts) instead of the caption. Before the first snapshot and while offline the orb uses the offline style and no caption shows.

4. Preload: add `chrome` functions `hover(over)`, `click()`, `drag(dx, dy)`, `dragEnd()`, `onVisibility(cb)`, `onCommand(cb)`, `sendState(state)`, `setIcon(dataUrl)` with validated numeric, boolean and data-URL arguments - window chrome only, no data (HUD data stays on the WebSocket, UI-SPEC). This plan wires `hover`, `click` and `onVisibility`; plan 01-27 wires the rest in main and renderer without editing the bridge.
