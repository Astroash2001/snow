1. Settings and secrets. `src/snow/config/settings.py`: `repo_root()`, `config_dir()` (env `SNOW_CONFIG_DIR` else `<repo>/config`), `data_dir()` (env `SNOW_DATA_DIR` else `%LOCALAPPDATA%\Snow`), `run_dir()` = `data_dir()/run`, `load_config(filename, model_cls)` parsing TOML with stdlib `tomllib` into a Pydantic model. `src/snow/config/secrets.py`: `Secret` wrapper (stores the value privately, `__repr__`/`__str__` return `Secret('***')`, `reveal() -> str`), `KEYRING_SERVICE = "snow"`, `get_secret(key_name: str) -> Secret | None` using `keyring.get_password("snow", key_name)`. No other key source exists (D-24).

2. Logging. `src/snow/logging.py`: `configure(process: str)` writes JSON lines to `data_dir()/logs/<process>.log` with stdlib logging (plan 01-11 replaces the internals with structlog and redaction; keep the signature). Log event names, ids and error kinds only, never transcript or reply text.

3. Worker client. `src/snow/common/hubclient.py`: `HubClient(url, token, role)` with `async run()` (connect, send Hello, reconnect with backoff 0.5 s doubling to 8 s), `publish(event)`, `send_command(command)`, and callbacks `on_event`, `on_command`, `on_snapshot` (the hub always sends a snapshot first, plan 01-01); sends `Heartbeat(worker=role)` every 2 seconds while connected. Reads `SNOW_HUB_URL`/`SNOW_TOKEN` env by default, else `run_dir()/hub.json`. Inbound messages are parsed with `WireMessage`; an unknown event type is logged and skipped so workers survive catalog growth.

4. Brain. `src/snow/brain/config.py`: `Provider(label, base_url, key_name, trust: Literal["trusted","untrusted"])`, `ChainEntry(provider, model, params: dict[str, object] = {}, drop_params: list[str] = [])`, `Role(chain: list[ChainEntry])`, `ModelsConfig(providers: dict[str, Provider], roles: dict[Literal["brain","fast","vision"], Role])`. `config/models.toml` minimal: provider `groq` (`base_url = "https://api.groq.com/openai/v1"`, `key_name = "groq"`, `trust = "trusted"`, `label = "Groq"`) and `[roles.fast]` chain with `{ provider = "groq", model = "openai/gpt-oss-120b" }` (plan 01-08 fills every provider and role per D-21 and D-22; per-model quirks live here, D-23). `config/persona.toml`: `system_prompt` = a short plain Jarvis-style instruction (calm, dry British wit, addresses the user as "sir", replies in plain speakable sentences); plan 01-16 replaces it. `src/snow/brain/worker.py`: `BrainWorker` handles `TranscriptFinal`: picks the first `fast` chain entry whose `get_secret(key_name)` is not None, builds `openai.AsyncOpenAI(base_url=..., api_key=secret.reveal(), max_retries=0, timeout=30)` (SDK retries would delay failover, research F6), calls `chat.completions.create(model=..., messages=[system, user], stream=True)` applying `params` and removing `drop_params`, publishes `ReplyDelta` per content chunk and one `ReplyFinal(text, emotion="neutral", big_moment=False, reply_source="llm", provider, model)` with the same `correlation_id`/`turn_id`. On an SDK error before the first chunk it logs the error kind and publishes nothing for that turn (plan 01-08 adds the chain and error events). Snow's own LLM is only the conversational brain here (D-20). `src/snow/brain/__main__.py`: `configure("brain")`, then runs `BrainWorker` under `HubClient(role="brain")`.
