  <action>
Wire one path: audio frames -> WakeGate -> TurnEngine -> GroqStt -> `transcript.final` on the hub (the brain from plans 01-03 and 01-08 then replies).

1. `config/voice.toml` + `src/snow/voice/config.py` (`VoiceConfig` Pydantic model): `[audio] input_device = ""`, `sample_rate = 16000`, `frame_samples = 1280`; `[wake] model = "hey_jarvis"`, `threshold = 0.5`, `patience_frames = 2`, `preroll_frames = 4`, `refractory_s = 1.5`, `strip_patterns` (case-insensitive regexes for a leading "hey jarvis" and common ASR variants such as "hey jervis", "a jarvis"); `[turn] vad_threshold = 0.5`, `start_secs = 0.2`, `stop_secs = 0.2`, `max_silence_secs = 3.0`, `max_turn_secs = 30`, `wake_alone_window_s = 1.0`, `barge_in_min_ms = 250` (used by plan 01-29); `[conversation] silence_timeout_s = 45` (inside D-08's 30-60 s; used by plan 01-18); `[stt.groq] base_url = "https://api.groq.com/openai/v1"`, `key_name = "groq"`, `model = "whisper-large-v3-turbo"`, `language = "en"`, `timeout_s = 8`. Plan 01-18 adds the `[phrases]` table.

2. `sources.py`: `AudioSource` protocol (`open(on_frame)`, `close()`, `is_open`). `MicSource` uses `sounddevice.InputStream(samplerate=16000, channels=1, dtype="int16", blocksize=1280, device=..., extra_settings=sounddevice.WasapiSettings(auto_convert=True))`; the PortAudio callback only copies the frame into a `queue.SimpleQueue` consumed by one processing thread. `FileSource(path, realtime=False)` reads a WAV (resample to 16 kHz mono int16 if needed), yields 1280-sample frames and appends 2 s of silence.

3. `wake.py`: `WakeGate(model, threshold, patience_frames, preroll_frames, refractory_s)` wraps `openwakeword.Model(wakeword_models=[...], inference_framework="onnx")`; when `model` is a bare name it calls `openwakeword.utils.download_models(model_names=[name])` once. A `collections.deque(maxlen=25)` ring of the last ~2 s of frames lives in RAM only. `process(frame) -> WakeHit | None` where `WakeHit(score, model, preroll)` and `preroll` is the last `preroll_frames + 1` frames (~320 ms before detection plus the current frame). After a hit call the model's reset and ignore hits for `refractory_s`.

4. `vad.py`: thin typed adapters `VadDetector.speech_prob(chunk_512) -> float` around Pipecat's `SileroVADAnalyzer` and `EndOfTurn.append(pcm, is_speech)` / `is_complete() -> bool` / `clear()` around `LocalSmartTurnAnalyzerV3` (check the real method names and sync/async shape in the installed source). Only these adapters import Pipecat; the rest of the voice code never does, so the framework stays removable. Pipecat's frame pipeline is not used: the brain is a separate process (D-40) and three of the four speech engines have no Pipecat service, so a plain asyncio pipeline is less code. Everything here runs on CPU (D-39).

5. `turn.py`: `TurnEngine(config, vad, eot, events)` - plain Python, driven only by audio time (samples processed), never wall clock, so file playback and the pre-roll burst behave exactly like live audio. States: `SLEEPING` (wake only), `AWAKE` (listening for turns), `MUTED` (used by plan 01-20). `on_wake(hit)` -> start conversation if sleeping, open a turn buffer seeded with `hit.preroll` (D-09: the words right after the wake phrase are part of the turn). `feed(frame)` splits frames into 512-sample chunks (keep a remainder), tracks speech start (`start_secs` of speech above `vad_threshold`) and end (`stop_secs` of silence and `eot.is_complete()`, or `max_silence_secs`), and calls `events.on_turn_end(turn_id, pcm, duration_ms, vad_stop_sample)`. Callback interface `EngineEvents`: `on_wake`, `on_conversation_start`, `on_turn_start`, `on_turn_end`, `on_wake_alone`, `on_conversation_end`, `on_presence`, `on_level` (plans 01-18 and 01-20 fill the flow callbacks).

6. `phrases.py`: `normalize(text)` (lowercase, unify apostrophes, strip punctuation, collapse spaces), `strip_wake(text, patterns) -> str`.

7. `stt_groq.py`: `GroqStt(cfg, get_secret)` with `async transcribe(pcm: bytes, sample_rate: int = 16000) -> str`: encode a WAV into `io.BytesIO` with stdlib `wave` (never a file path, D-18), call `AsyncOpenAI(base_url, api_key, max_retries=0, timeout=cfg.timeout_s).audio.transcriptions.create(model=cfg.model, file=("turn.wav", buffer, "audio/wav"), language="en", response_format="json")` (D-37). Errors raise `SttUnavailable(kind: Literal["no_key","rate_limited","unreachable","offline"], retry_after_s: float | None)` (429 -> rate_limited with the `retry-after` header; connection/timeout/5xx -> unreachable; missing key -> no_key).

8. `pipeline.py`: `VoicePipeline(cfg, hub, source, wake, engine, stt)`. The processing thread feeds WakeGate and TurnEngine; engine callbacks hop to the asyncio loop with `loop.call_soon_threadsafe` and publish `wake.detected` (first, immediately), `conversation.started(trigger="wake")`, `presence.state(listening)`, and after `await stt.transcribe(...)` a `transcript.final(text=strip_wake(...), stt_source="groq", duration_ms)` with the conversation's `correlation_id` and the turn's `turn_id`; empty text publishes nothing. Groq is called only for a wake-opened turn. `__main__.py`: `python -m snow.voice` calls `snow.logging.configure("voice")` and runs `HubClient(role="voice")` + `VoicePipeline(MicSource)` (plan 01-20 adds the startup mute rule).

9. Tests: `tests/voice/conftest.py` (fixture loader for `tests/fixtures/audio/`, `FakeHub` capturing published events, respx route for Groq `POST /openai/v1/audio/transcriptions`). `test_voice_turn.py` (end to end with real openWakeWord, Silero and Smart Turn on CPU and an in-process hub): each `wake_cmd_gap*.wav` produces wake.detected then exactly one transcript.final whose text has the wake phrase stripped, and the uploaded WAV is at least the command's duration plus 0.3 s (pre-roll kept the first word); `mid_thought_pause.wav` produces exactly one transcript.final containing both halves (VOIC-05 groundwork).
